CSS

oceanusc2023/9/5大约 1 分钟CSS介绍

CSS 指层叠样式表 (Cascading Style Sheets)，它负责描述网页元素的具体样式。

CSS3 是最新的 CSS 标准，被拆分为"模块"。模块包括: 选择器、盒模型、背景和边框、文字特效、2D/3D 转换、动画、多列布局、用户界面。
