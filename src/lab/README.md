## 从笔记到实践

- 学习 Git 时，把命令整理成[专题导图](./mindmap.md)。
- 写页面时，用 [CSS 实验室](./doodle.md)寻找图案灵感。
- 看到喜欢的图片时，用[图片取色](./colors.md)收集配色。
- 写教程时，用[手绘标注与卡片动效](./annotations.md)强调关键内容。

这些小工具分别基于 [Markmap](https://github.com/markmap/markmap)、[css-doodle](https://github.com/css-doodle/css-doodle)、[Color Thief](https://github.com/lokesh/color-thief)、[Rough Notation](https://github.com/rough-stuff/rough-notation) 和 [VueUse Motion](https://github.com/vueuse/motion)。
