# 专题导图

把 Markdown 大纲变成一张知识地图。可以从 Git、Linux 或博客内容示例开始，也可以粘贴自己的笔记。

## 使用方法

1. 用标题表示主题，用缩进列表表示分支。
2. 点击「生成导图」，再点击分支圆点折叠或展开内容。
3. 调整好展开状态后下载 SVG；文件包含文字，可用浏览器打开。

输入仅在当前页面中使用，不会自动保存。离开前请保留原始 Markdown。为保持图表清晰，链接以文字呈现，不加载外部图片或嵌入 HTML。

想系统学习这些命令，可以继续阅读 [Git 教程](../software/git/)和 [Linux 笔记](../linux/)。

由 [Markmap](https://github.com/markmap/markmap) 提供导图能力。
